# personal/

Freeform personal catch-all space — notes, ideas, scratch scripts, working copies of
career documents. Nothing in career-ops reads this folder programmatically, no schema is
enforced, and no update process may touch it (User Layer per `DATA_CONTRACT.md`).

Everything under `personal/` except this README is gitignored: this repo is public, and
this folder's contents are personal data that must never be committed or pushed.

Conventions in use (not enforced):

- `notes/` — freeform notes and idea lists (e.g. `notes/star-stories/` holds working
  copies of STAR(R) interview-story material; `interview-prep/story-bank.md` remains the
  canonical, structured store for finalized stories)
- `scripts/` — ad-hoc personal scripts (e.g. read-only metric extraction), with their
  data output under `scripts/output/`
